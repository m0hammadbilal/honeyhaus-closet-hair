# HoneyHaus — Closet & Hair

This download contains the current static HoneyHaus site build.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server:

```bash
cd dist
python3 -m http.server 8080
```

The site includes its HTML, CSS, JavaScript, product assets, hero imagery, logos, and the Sites hosting manifest.
